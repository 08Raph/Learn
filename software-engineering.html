🎓 Learn to Code

A free software-engineering study pathway

Six stages, from a complete beginner to master's-level topics: 52 courses with lessons, worked examples, labs, examinations and projects. Self-paced, free and in your browser. It is not an accredited degree: certificates are completion records of this website.

Open the University

Stage 1: Foundations of Computing and Programming

Complete Beginner. Start from nothing. Learn what computers do, how to think in steps, and write your first programs in Python, JavaScript, HTML and CSS.

  • SEU 101 How Computers Work
  • SEU 102 Problem Solving and Algorithms
  • SEU 103 Programming Fundamentals I
  • SEU 104 Programming Fundamentals II
  • SEU 105 Introduction to JavaScript
  • SEU 106 HTML and CSS Foundations
  • SEU 107 Terminal, Files and Git
  • SEU 108 Foundations Project Studio

Stage 2: Core Software Engineering

Junior Software Engineer. Object-oriented programming, data structures, algorithms, databases, testing and teamwork with Git: the toolkit of a working junior engineer.

  • SEU 201 Object-Oriented Programming
  • SEU 202 Data Structures I
  • SEU 203 Algorithms I
  • SEU 204 A Tour of Languages
  • SEU 205 Databases and SQL
  • SEU 206 Git Collaboration and GitHub
  • SEU 207 Testing, Debugging and Clean Code
  • SEU 208 Junior Project Studio

Stage 3: Building Real Systems

Intermediate Software Engineer. Architecture, security, networking, operating systems, concurrency and delivery. You learn how the pieces of a production application fit together.

  • SEU 301 Advanced Data Structures and Algorithms
  • SEU 302 Object-Oriented Design, SOLID and Patterns
  • SEU 303 Software Architecture and APIs
  • SEU 304 Authentication and Web Security Basics
  • SEU 305 Databases II
  • SEU 306 Networking
  • SEU 307 Operating Systems and Concurrency
  • SEU 308 Testing, CI/CD and Containers
  • SEU 309 Intermediate Project Studio

Stage 4: Systems at Scale

Advanced Software Engineer. Distributed systems, system design, performance, compilers, Rust, security engineering and cloud reliability.

  • SEU 401 Distributed Systems
  • SEU 402 System Design and Scalability
  • SEU 403 Microservices and Domain-Driven Design
  • SEU 404 Performance Engineering and Memory
  • SEU 405 Rust
  • SEU 406 Compilers and Language Design
  • SEU 407 Security Engineering
  • SEU 408 Cloud, Kubernetes and Reliability
  • SEU 409 Advanced Project Studio

Stage 5: Theory, Mathematics and Research

Computer Science and Master's-level Studies. The mathematics and theory under everything else: proofs, complexity, computability, machine learning, formal methods and research skills.

  • SEU 501 Discrete Mathematics
  • SEU 502 Probability, Statistics, Linear Algebra and Calculus
  • SEU 503 Theory of Computation
  • SEU 504 Advanced Algorithms
  • SEU 505 Computer Architecture and Parallel Computing
  • SEU 506 Advanced Database Systems and Information Theory
  • SEU 507 Machine Learning and Artificial Intelligence
  • SEU 508 Formal Methods, Semantics and Compiler Construction
  • SEU 509 Advanced Cybersecurity and Privacy Engineering
  • SEU 510 Research Methods

Stage 6: Professional Mastery

Professional Software Engineer. Principal-level architecture, reliability and security at scale, technical leadership, AI engineering, and three capstone projects that prove independent judgement.

  • SEU 601 Principal-Level Architecture and Large-Scale Systems
  • SEU 602 Reliability, Performance and Security at Scale
  • SEU 603 Technical Leadership and Engineering Management
  • SEU 604 Engineering Economics, Licensing and Product
  • SEU 605 AI Engineering and MLOps
  • SEU 606 Capstone I: Production-Style Full-Stack Application
  • SEU 607 Capstone II: Distributed System
  • SEU 608 Capstone III: Computer Science or AI Research Project
